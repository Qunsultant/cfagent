## Corrections to the task brief (verified in code)

1. **"15-factor scoring" is a misnomer.** In this repo "15-factor" is the 15-factor *architecture re-audit* framework (e.g. `src/telemetry/screenRunStats.ts:2`, `src/server/routes/core.ts:111` `fifteenFactorCompliant`). The screener's actual scoring is: (a) `screenScore` 0–100 composite of day momentum, intraday position, 52-week position, value zone (`src/trading/screenerReportPdf.ts:395`, `src/trading/screeningIndicators.ts:49-153`); (b) 6-vote composite bias — P>SMA50, P>SMA200, SMA50>SMA200, MACD>0, RSI14>50, regime UP (`src/trading/screeningIndicators.ts:215-260`); (c) 5-factor SA-style grades Value/Growth/Profitability/Momentum/EPS-Revisions, of which **only Value and Momentum are ever graded** — Growth/Profitability/Revisions are always null ("withheld, never faked", `src/trading/factorGrades.ts:1-51`, `src/agents/screener-agent.ts:1383-1408`).
2. **Universe default is not uniformly nasdaq100.** Planner default is `TECH` (`src/workflows/stockScreenPlanner.ts:64`, `ScreenerRunRequest` comment `src/agents/screener-agent.ts:152`); the run-lock default is `nasdaq100` (`screener-agent.ts:891`); scheduled default is `NASDAQ100` (`src/services/scheduledTasks.ts:1542`). Any J definition must pin which default it preserves.
3. **Universe set:** TECH, NASDAQ100, SP100, SP500, RUSSELL2000, ETF, LEV_ETF, ALL (`src/trading/universes.ts:17-24`). ALL is never resolved directly — it auto-shards (`universes.ts:164-165`, `screener-agent.ts:2021-2026`).
4. **J generate has no XLSX.** `GENERATE_FORMATS = ["json","markdown","csv","pdf"]` (`src/services/generateJobs.ts:158`); stock needs PDF+XLSX+CSV.
5. **#3930 at this ref is tiny:** `git show --stat 817a5218` touches only `src/services/feedJobs.ts` (6 lines) + one test — one parameterized fundamentals job (`yahoo-nasdaq100-fundamentals`, `parameterizedUniverse: true`, `feedJobs.ts:331-349`) joined by every enrich job (`src/services/enrichJobs.ts:332-380`, `ENRICH_FUNDAMENTALS_ELEMENTS`, 14 elements).
