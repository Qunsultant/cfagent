### Changed

- **Public.com never reads "Paper", and selecting it arms live with a confirmation (Qunsultant/cfagent#4649):** the broker catalog now declares `paperMode` per broker (total by type; Public is the only `false`), and every surface reads that one fact instead of inferring "TEST means simulated". The top-left crumb renders `Public.com / Live Execution` in both stored modes (`brokerModeLabel` takes the broker id), while E*TRADE and Alpaca keep `Paper`. Selecting Public.com while the stored mode is TEST opens a danger `ConfirmModal` (the sanctioned primitive, `on Modal`) that names the broker, says orders will place with real money, says the mode is global, and explains that Public has no paper mode; confirming stores the broker **and** switches the mode to PROD, cancelling changes nothing. While the impossible `public + paper` pair still holds (a stored row from before this change, or a deliberate live→paper switch) the settings menu and the trading hub show a persistent inline `Notice` above the Approve button; preview is not blocked, because the server already refuses placement.
