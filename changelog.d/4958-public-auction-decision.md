### Changed

- **Public auction orders: recorded as unsupported by decision, with the reason named (Qunsultant/cfagent#4958):** Public's hosted order schema exposes no time-in-force field that can be verified, and its published API documentation indexes the order endpoints without a field table — so an auction term (`opg`/`cls`, i.e. MOO/MOC/LOO/LOC) has nothing to ride. Rather than invent one, the seam keeps refusing every non-default term by name (`PUBLIC_TIME_IN_FORCE_UNVERIFIED`) and the message now states the actual reason — *no verifiable time-in-force field, auction terms included* — instead of a generic "unverified". A test pins both halves: an auction term takes the named refusal, and the single-leg order spec carries **no** `time_in_force` key at all, so the absence is structural rather than an oversight. Lifting this needs the live schema verification owned by gap 14 (Qunsultant/cfagent#4668).
