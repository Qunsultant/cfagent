### Added

- Screener delivery-config visibility (#1770 slice B, F-63): a named `checkScreenerDeliveryConfig` check (new `src/services/screenerDeliveryConfig.ts`) reports which email transports a deployment has — cfpay A2A, the `env.EMAIL` binding, or none — with a named missing reason when none exists. The bus publishers now skip email with that named warning instead of dropping a failed/absent local send silently, and scheduled stock screen runs carry the bus-path config status in their task result data (`deliveryConfig`) when email was requested. RESEND_API_KEY/SMTP variables are reported by name as set-but-unconsumed: no sender on current main reads them, so setting one does not enable delivery. No change to followup delivery, report download, or the #1209 delivery hold. Pinned by `tests/screener_delivery_config_1770.test.ts`.
