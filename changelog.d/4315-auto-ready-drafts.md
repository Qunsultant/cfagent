### Added

- **Draft PRs go ready when their checks go green (#4315):** publish-early opens a draft as soon as Tier 1 passes, but nothing flipped it to ready, so the chain stopped at `ready_for_review` and needed a human click (#4296). A new `auto-ready-drafts` workflow watches the five gating workflows finish, re-evaluates the head SHA with the watcher's verdict (latest run per workflow name, cancelled/skipped never deciding, a missing run pending, all five required), and marks an eligible draft ready — only a draft that carries the `auto-merge` label, re-checked immediately before the flip, with an already-ready 422 tolerated. After that the existing chain runs untouched: `ready_for_review` → label → queue entry → merge. The workflow uses the run's own scoped token, no App credentials, no PR checkout, and no privileged trigger. #autoclaw-001
