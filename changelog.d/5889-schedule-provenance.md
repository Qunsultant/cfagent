### Added

- Schedule provenance on the Schedules home (#5889): every row now shows its source — a Source column (source label, job identity, arming origin) on the list itself, the same source in the row detail dialog, and view buttons to filter the list by source (per source kind, plus the Cron timing slice), per agent, and per workflow. Sources are derived once on the server from the existing list join (`listUnifiedScheduleItems`), reusing each record's provenance field where present and the #5880 job catalogue for job identity: seeded, derived, declared task, sweep/watchdog alarm, user-created, agent-created, pipeline job, worker duty, workflow, ticker push, system, and unknown for legacy rows whose creation was never recorded. The Cron view is a timing slice (every cron-timed row, whatever its source) that overlaps Derived by design; each row still carries exactly one source, so nothing is double-counted. Per-agent and per-workflow views list only the agents and workflows the loaded rows actually name.
