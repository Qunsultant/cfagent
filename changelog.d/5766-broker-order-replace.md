### Added

- **Stock Copilot can update an open order in place on any routed broker (#5766):** replace existed as `alpaca_replace_order` and as the neutral `POST /broker/order/replace` route, but not as a tool that works whichever broker holds the order. The new synchronous `broker_order_replace` tool routes through one seam (`replaceOrderViaSelectedBroker`) shared with the route: the platform resolves the broker (the model never names one), only the fields the caller states are sent so an unstated term keeps its broker value, and an empty replace is refused rather than forwarded. A broker that cannot replace an order refuses **by name** — nothing is cancelled and re-placed behind the user, which would drop queue position and detach bracket legs. Gated as `mcp:trade`, requires the chat turn's acting identity, and listed in `SYNCHRONOUS_MCP_TOOLS`. #ceo-aimp
