### Changed

- **No containers and no scheduled work in the deployment (#4112, owner direction).** `wrangler.jsonc` no longer declares a live `"containers"` block or a live `"triggers"` block, and the `SCREENER_WORKFLOW` binding no longer carries `"schedules"`. The deployment provisions no container and registers no cron or workflow schedule, so nothing fires on a timer. The commented-out container block records the only shape a re-enable may take — `max_instances: 1`, `instance_type: "lite"` — and the cron expressions survive as comments so restoring a schedule is an uncomment, not a code change. The `SandboxAgent` class, its binding, the `scheduled()` handler and `resolveCronEntryPoint` all stay; they become unreachable rather than deleted. Pins updated in the same change: the container structural pin, both cron-parity pins, the workflow-binding schedule pin, and the mesh registry/view cells that cited the wrangler declaration as fact.
