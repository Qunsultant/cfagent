### Added

- **Stage detail for the last run, and human labels, on the workflow catalog (#3074, #3075):** each stage row now carries a **Stage detail (last run)** column showing what the run actually recorded for it - the stage's own detail line, the reason it stopped, its error (danger notice), its start/finish window, the capability that ran it, and a capped view of its output (artifact keys included). A stage with no row in that run says so; a family with no run says to run the workflow. The page also stops rendering raw keys: the registry now carries human `label`s for every workflow and stage ("Stock screener", "Analysis (screen)", "Deliver (channels)"), rendered by the panel, and `assertWorkflowCatalog` refuses an empty label so a key cannot reach the UI again. Six new pins across the detail, last-run, panel and registry suites; UX-conformance and bespoke-ceiling suites green.
