### Changed

- **Feed providers resolve through the provider × dataset matrix (Qunsultant/cfagent#5494):** the feed path no longer selects a provider with `switch (def.sourceId)`. `config/vocabulary.json` now carries `providerDatasets` — one row per served pair, with the batch flag and (from the dataset entry) the capability it delivers — and `resolveProviderDataset()` in `src/config/vocabulary.ts` is the one reader. The capture-wired factory looks the pair up and then picks a builder from a per-provider registry, so an unserved pair refuses by name (`REFUSAL_VOCABULARY_UNSUPPORTED_PAIR`, naming both axes and listing what that provider does serve) and is never re-routed to a provider that happens to serve the dataset — never broker-for-broker, per #5515. The batch-quotes requirement is the pair's declared `batch` flag rather than a duck-typed `getQuotesBatch` read, with the method check kept only as a conformance guard. Adding a dataset or a provider/dataset pair is now a data-only change; every pair the engine serves today resolves identically, pinned. #CAIO-quns
