### Added

- **Public carries the on-close auction orders (MOC / LOC) — and says why the on-open ones do not exist (Qunsultant/cfagent#4958):** the previous slice recorded Public as "unsupported" because the integration's order spec carries no time-in-force field. That was half the story. Public **does** document auction participation, as two of its own **order types**: `MARKET_ON_CLOSE` and `LIMIT_ON_CLOSE` — so `cls` now maps onto them at the seam (market → MOC, limit → LOC with its limit price) and reaches the broker on the wire, instead of being refused. Public publishes **no on-open type** (`MARKET_ON_OPEN` / `LIMIT_ON_OPEN` appear nowhere in its contract), so `opg` is refused **by name** with `PUBLIC_AUCTION_ON_OPEN_UNSUPPORTED`, citing what Public does and does not document — never silently placed as a day order. The capability matrix lists `CLS` (not `OPG`) for Public live equity; Public has no paper mode, so the TEST matrix stays empty. Lifting the on-open limit would need Public to publish the type — that is a broker change, not a code change (the hosted-schema verification stays with gap 14, Qunsultant/cfagent#4668).
