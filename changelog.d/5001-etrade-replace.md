### Added

- **E*TRADE order replace, through its own change flow (Qunsultant/cfagent#5001):** the neutral replace route refused E*TRADE by name; it now runs the broker's documented **change preview → change place** pair. Two things make it honest rather than a wrapper: the order is **read first**, so a status that is no longer open is refused by name before any broker call; and the receipt reports the **new order id the broker assigns** (E*TRADE cancels the original), saying so explicitly instead of pretending the same order changed in place. The change body states the whole order — the caller's quantity/price/time-in-force where given, the order's own values where not — and a stop order whose trigger this surface cannot read is refused with `state stopPrice` rather than sent with a guessed price. The registry's `replace` capability is now native on both brokers that document it, and a compound parent stays refused on both.
