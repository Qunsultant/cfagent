### Added

- **Retry marker in Docs (#4423):** a retried chain is ONE Docs row by design — the retry is idempotent with the original, so the row was indistinguishable from a first attempt. The store shard now records the chain's retry lineage in the canonical row body (`retriedShards` from the rows that name a `retryOf`, `shardAttempts` from the attempt history #4417 persists), the run summary and the Docs row carry it, and the Docs table renders **`Retry ×N`** with a tooltip naming the failed attempts. A run whose store records no lineage keeps the field absent and renders no marker — "no retry" and "not recorded" stay distinguishable. The attempts column is read tolerantly, so a store that predates the #4417 migration reads 0 recorded attempts instead of failing the chain read. #autoclaw-001
