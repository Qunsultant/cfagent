### Added

- **Strategy screen job definition (Qunsultant/cfagent#4271):** the strategy screen now defines a dedicated engine job (`strategyScreenJobDefinition`, job id `strategy-screen:<runId>`, root kind `strategy-screen`) instead of riding the options job — so a strategy screen is visible as its own job in Workflow Runs with its own pipeline record and run history. The eight stages, steps, and execution are identical to the options dispatch; only the job identity changes. The NLQ panel/scan legs, the panel/scan helpers, the manual panel, the scheduled scan, and the per-symbol shards all define strategy jobs now; the plain options screen, the goal options leg, and the E*TRADE options route keep the options job. Per-stage control for strategy runs is S2 (#4272); the control plane still addresses options jobs only.
