### Added

- **Pipeline settings map now takes effect on runs (#4782 S3):** the per-tenant `pipeline.*` settings (retry budgets, notification toggles, fetch timeout) resolve at the pipeline engine's construction sites and the report-path call sites, so an operator's tuning changes retry behavior without a deploy; `jitterRatio` is overridable per bucket and shared (`pipeline.retry.<bucket>.jitterRatio`, `PIPELINE_<BUCKET>_RETRY_JITTER_RATIO`, clamped 0–1); the three live parent poll intervals resolve through config (`SCREEN_DOOR_PARENT_POLL_MS`, `CHAT_SCREEN_PARENT_POLL_MS`, `CHAT_AWAIT_POLL_MS`) with the `ctx.workflowPollIntervalMs` override channel wired; and the Settings menu gains a Pipeline policy panel (GET/POST `/api/trading/settings/pipeline-policy`) for managing the globals. #CDO-mha7
