### Added

- **Public order replace, with the broker's own bracket rules (Qunsultant/cfagent#5002):** replace was the last broker gap on the neutral route. Public exposes it as `cancel_and_replace_order` — a tool our client already allow-listed — and documents the body: the order being replaced, a **fresh `requestId`**, the order type, the expiration and the changed terms. The order is **read first**, because Public's rules depend on what it is: a bracket **entry** cannot be replaced (its exits would be orphaned) and answers `replace_parent_unsupported`; a bracket **leg** may change its **price only**, so a quantity change on a leg is refused by name; and only an order still open is replaceable at all. Only the changed fields travel, plus the fresh request id. Public applies replacements **asynchronously**, so the receipt reports **acceptance** — "confirm it with the order read" — and never claims the order has already changed. TEST mode refuses before any MCP call, as Public has no paper mode.
