### Added

- **Feed-job refresh-leg timeout (#3992 PR-2):** the universe hydration await in `resolveUniverseListWithHydration` (`src/services/feedJobs.ts`) is now raced against the PR-1 substrate bound `FEED_JOB_TIMEOUTS.refreshMs` (30s) via `withFeedDeadline`. A refresh that never settles no longer hangs a feed run forever with nothing recorded: the run settles and records exactly one failed run with the stable code `FEED_REFRESH_TIMEOUT`, distinctly from `FEED_UNIVERSE_REFRESH_FAILED` (a refresh that threw or produced no usable list) and from the bare `FEED_UNIVERSE_MISSING` (no refresh wired — behaviour there is unchanged, no race and no timer). The wiring lives in the one helper shared by the quotes, fundamentals, technicals, and sentiment runners, so all four record the timeout the same way; a refresh that settles in time behaves exactly as before, and a refresh abandoned by the race may still land its index snapshot in the background without moving the recorded outcome. Provider-fetch and capture legs remain unbounded until PR-3, and the pipeline deadline lands in PR-4.
