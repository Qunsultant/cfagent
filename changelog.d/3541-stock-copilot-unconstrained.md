### Added

- **Stock Copilot unconstrained multi-session execution & side-by-side chat workspace (#3541):**
  - **24/7 Trading Sessions Default:** `DEFAULT_COPILOT_SESSIONS` now defaults to all four canonical sessions (`pre_market`, `regular`, `after_hours`, `exto`) out of the box, eliminating the "The pre-market session opened — it is not one of your enabled sessions" block and enabling continuous autonomous operation. `parseCopilotSessionList` supports `"all"` and `"*"` aliases; `STOCK_COPILOT_IGNORE_SESSIONS` / `STOCK_COPILOT_FORCE_ALL_SESSIONS` allow full session bypass via env.
  - **Externalized Non-Blocking Mode Alignment:** Mode selection in unconfigured tenant environments automatically aligns with deployment pins (`ALPACA_TRADING_TYPE="live"` / `STOCK_COPILOT_MODE`) instead of blindly defaulting to paper, preventing mode mismatch refusals ("The mode guard refused this cycle"). `STOCK_COPILOT_STRICT_MODE_GUARD="false"` / `STOCK_COPILOT_AUTO_ALIGN_MODE="true"` allows permissive mode auto-alignment; `STOCK_COPILOT_BROKER_NEUTRAL="true"` externalizes broker neutrality.
  - **Side-by-Side Dashboard & Chat Workspace:** Replaced vertical height squishing on `?tab=chat&view=stock` with a responsive split workspace. The left pane hosts the full `StockCopilotPanel` dashboard (positions, exit plans, session toggles, telemetry), while the right pane provides the interactive chatbox (conversation stream, Stock Copilot welcome hero with quick chips, and sticky input composer). Users can ask questions about open positions, cycle telemetry, and CVaR risk, as well as pause/resume the loop directly through chat input. #ceo-aimp
