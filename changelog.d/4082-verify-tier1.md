### Added

- **The shared Tier 1 gate now exists (#4082):** §7 has named `scripts/verify-tier1.sh` as "one shared Tier 1 script … identical for every lane" since the tiered-verify decision (#4052), but the file was never committed — the gate existed only as a list of steps in a doc, so every lane either retyped it (drift) or skipped a step (silent gap). The script composes the pieces that already existed: strict typecheck → the **affected suites** selected from the diff (changed test files plus tests that reference a changed `src/` module, capped with `--max-affected`) → the pin suites (`npm run test:pins`, which already carries the censuses, router inventory and policy-gate guards) → the migration latest-pin lint → the changed-file lint ratchet → the Policy Gate diff checks. `--list` prints the selection without running anything, `--no-fetch` works offline against the local `origin/main`, and the summary reports each step's pass/fail with its duration. It deliberately does **not** run the full suite or the build — that is Tier 2 in CI, and the merge gate is the queue plus required checks. §7 now describes the invocation it names. #clo-arsi
