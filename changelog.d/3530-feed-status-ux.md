### Added
- Feed status UX (#3530): the Data Providers panel now renders each source's direct feed-job status from the status API's per-provider feed block — the job's last run (time, trigger, outcome with its stable error code on failure), the persisted local copy's state (rows, age, as-of provenance, stale marker, or "none usable"), and the dataset facts (universe, cadence, stale-after) — with a "Run now" control wired to the existing direct feed-run route whose outcome is surfaced as it came back (a failed run is reported as a failure, never as success). States are honest and distinct: never-run, last-run-failed, stale, ready, not-configured, and — for Nasdaq, whose listed-securities universe does not fit the quotes feed contract — an explicit "no feed job for this source" with the reason, instead of the previous indistinguishable empty state.
