### Referral / invite codes: server delivery

- Referral and invite codes are now issued, redeemed, and managed server-side: five new tables (`agent_referral_code_rules`, `agent_referral_codes`, `agent_code_redemptions`, `agent_code_redemption_counts`, `agent_code_run_balances`), operator-only rule routes, operator/tenant-admin issue routes, a self-service issue route, revoke routes, a redeem route, and a code-runs balance read. A redeemed code credits runs to the redeemer's code-runs balance; codes confer runs only — never tier, never credits, never a price, never access. Rule terms are snapshotted at issuance and caps are enforced live at redemption; a missing or inactive rule disables codes for that product and issuer. The gate step that spends code runs, the Products panel, and the billing-tab redeem surface land in slice 2.
