### Added

- Admin surface for logged-in users (#2836): `GET /api/iaaa/logged-in-users` lists active sessions (issuer:subject, tenant, created/last-seen/expiry, provider) plus per-user recorded login counts, first/most-recent/recent login times, and per-user session history, and `POST /api/iaaa/logged-in-users/revoke` revokes one session immediately with an audit record. Platform admins see all tenants; tenant admins see only their own tenant; non-admins are denied (audited). Built against the existing durable records only (SessionStore sessions, retained auth.login audit events, login-alias and binding records) — login counts cover retained audit events only and are labelled as such, never presented as lifetime totals. IAAA Admin → Overview gains a "Logged-in users" section, also reachable by tenant admins through the limited view. #CISO-bhdm
