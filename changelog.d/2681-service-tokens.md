### Added

- Tenant-bound service tokens (`svc_`) with a provisioning + role UX (#2681): hash-only storage in the SessionStore `service_tokens` bucket, secret shown once at mint/rotate, required expiry, immediate revocation, platform/tenant tier binding with cross-tenant denial + audit, `canGrantRole`-enforced roles, and Bearer acceptance on the catch-all `/api/` forwarder (session first, token second; token callers never administer tokens). IAAA Admin → Overview → Service tokens panel beside Service user.
- Shared-orchestrator address migration (#2681): the live address is now `shared_orchestrator`; a platform-admin migration (`POST /admin/orchestrator-migration/migrate`) copies SDK schedules, paused_schedules, all KV keys, and user SQL tables from the legacy instance (in-flight async-job rows drain on the source; SDK internals and chat session excluded), verifies counts, and writes a receipt. The legacy address survives only as `LEGACY_SHARED_ORCHESTRATOR_INSTANCE` (migration source + deny guard for in-flight queued messages).
