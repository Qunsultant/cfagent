### Added

- **Presets tab (#2886, under #2764, full-stack #2766):** new hub tab `?tab=screeners&view=presets` (canonical `?view=`, legacy aliases preserved) with My Presets (the existing ScreenerPresetManager reused as-is: list, save, load into the criteria panel, delete own preset; mas_screener_presets via the existing preset routes) plus proposed starter presets. Starters are read-only proposals (names proposed, NOT finalized): Trend Breakout, Pullback Reversion, Momentum Leaders, Oversold Bounce, Volume Surge, 52-Week Strength, Value Zone, Squeeze Watch. Choosing one COPIES it to My Presets (POST); starters are never edited. 52-Week Strength and Value Zone honestly carry null criteria (no expressible filter field yet) with copy/apply disabled — no invented thresholds. Presets strictly separate from patterns: the tab never reads pattern definitions; name overlap is labeled. Built only from `src/client/components/ui/` primitives.
