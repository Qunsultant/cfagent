### Added

- **Chat can select the data-provider axis (#5500):** `manage_tenants` `settings-update` now resolves `dataProviderId` — and `brokerId` with it — through the whole-set vocabulary (#5515) before the value reaches the tenant route. An alias or differently-cased value resolves to its canonical id; an unknown value refuses by name with the vocabulary's own code (`REFUSAL_VOCABULARY_UNKNOWN_VALUE`), listing what may be chosen; a broker that serves no dataset (`tastytrade`) refuses on the provider axis instead of being written and rejected later by the engine. The tool's published schema and description name the known values, so the model asks for a real one instead of guessing.
