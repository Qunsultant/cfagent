### Added
- Stage storage threaded through the panel path (#4400): a panel run over caller-supplied engine stores writes its stage artifacts into the stores' artifact store, scoped by the executing engine run id (bound per step invocation); a control rerun with no caller-supplied storage reads them back from the same stores. A rerun whose run never threaded its artifacts refuses by name (`stage_storage_unavailable`) before any execution instead of reporting a completion it did not execute; the first stage (plan) is exempt. Caller-supplied storage and panel runs without engine stores are unchanged.
