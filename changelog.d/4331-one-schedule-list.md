### Changed

- **One schedule list, filtered by the owner's ten kinds (#4329 S2, #4331):** the schedules home no longer splits its inventory into the options manager's embedded list and a separate "Other Durable Schedules" table. Every durable schedule is one row in the one table — screening callbacks included — and the options manager keeps its form, latest runs and audit trail without a list of its own. The filter bar is the owner's set (All, Stocks, Options, Strategy, Goal, Payment, Trading, System, Queued, Other), configured in `src/config/scheduleListModes.ts` (`SCHEDULE_LIST_FILTERS`, `SCHEDULE_LIST_DEFAULT_FILTER`) with the same resolution rules as the run ledger's kinds, and classification comes from one classifier (`src/services/scheduleKinds.ts`) over the recorded callback, type and payload: a delayed job is Queued whatever it would do, options/strategy precede trading, a universe payload marks Stocks, the platform's own upkeep is System, and an unmatched callback is Other — never dropped, never guessed into a family. With the embedded list gone, the page's only destructive row action is Delete. #autoclaw-001
