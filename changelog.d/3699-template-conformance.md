### Issue templates: per-doc conformance checklist + journey impact (Qunsultant/cfagent#3699)
- Issue templates (task, bug report, enterprise architecture) now require a per-doc conformance checklist (platforms.md, ADD.md, standards.md, gitops.md, tech-standards.md, anti-drift.md, ux-architecture.md) and a before/after user-journey impact statement; bug_report.md gains a User journey section. Templates moved from `.github/templates/` to `.github/ISSUE_TEMPLATE/` so GitHub surfaces them in the New Issue chooser; `.github/ISSUE_TEMPLATE/config.yml` disables blank issues and links Discussions and private vulnerability reporting. `docs/agents/gitops.md` §5 updated to match the templates.
- PR templates: `.github/templates/pull_request_template.md` moved to `.github/pull_request_template.md` (content unchanged — still the auto-filled default), and `.github/PULL_REQUEST_TEMPLATE/` now holds two variants selectable with the `template` query parameter: `hotfix.md` (urgent production fix, gitops §18.2 emergency rules still apply) and `docs.md` (docs/chore, no type label required). Both variants preserve the gate-critical fields: `## Agent` hashtag, full `OpenAIMP/cfagent#<number>` linked-issue reference, changelog.d entry instruction, and the `Process documentation impact:` line.
