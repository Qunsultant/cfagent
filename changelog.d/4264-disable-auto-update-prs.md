### Changed

- **The auto-update PR bot is off; the merge queue is the only rebuilder (#4264):** `auto-update-prs-app.yml` brought `main` into every open *unqueued* PR branch on each `push` to main, on CI/CodeQL completion, and on a 5-minute cron. With the merge queue configured that is redundant and harmful — §11 has the queue build each entry on the latest base and run `merge_group` checks there, so an up-to-date branch is not a precondition; it updated by **merge commit**, the practice §6/#1853 forbids (merge commits make rebase-merge refuse later); and it starved PRs of a green window — on 2026-11-12 #4219's head moved three times in ~20 minutes, restarting five required checks each time, which is why the oldest PRs in the backlog never merged. Triggers are now `workflow_dispatch` only. No capability is lost: the auto-merge/auto-enqueue half already lives in `auto-merge-trusted.yml` (#1509), and the update half is what the queue now does correctly; the update logic stays intact for manual runs, and the reason is recorded in the file's header against §11 and #1853. #autoclaw-001
