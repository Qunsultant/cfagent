### Added

- **Patterns tab (#2884, under #2764, full-stack #2766):** new hub tab `?tab=screeners&view=patterns` (canonical `?view=`, legacy aliases preserved) with a read-only stock pattern catalog from the existing setup catalog, stock families only (trend_breakout, pullback_reversion — options families never listed, nothing seeded). Each pattern shows signature, indicators, guardrails, paired strategies, risk notes, and its screen filter. Select/apply sets the New Screen criteria panel via the existing `stockFilterToCriteria` mapping and navigates to new-screen (trend_breakout -> momentum bullish_breakout; pullback_reversion -> maxRsi 30). Guardrails with no filter field (volumeRatioMin) stay visible as metadata and are never silently converted. Read-only in v1 (no add/update UI — later phase). Patterns strictly separate from presets: preset storage untouched. Built only from `src/client/components/ui/` primitives. Capability inventory pattern entry updated to canonical in the same PR.
