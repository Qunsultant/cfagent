### Added

- **Inner per-symbol engine stages in the shard detail (#4420):** an options feed shard dispatches its per-symbol strategy scan as `strategy-screen:shard-scan:<chainId>:<symbol>` and that engine run checkpoints durably — but nothing read it, so a failed shard showed only its shard-level failure. The Workflow Runs read now derives that inner job id from the shard's own payload, reads its checkpoint from the same store the shard wrote it to, and projects it with the one stage projection the job surfaces already use. The shard detail renders the inner stages (status, start, end, duration) under **Inner engine stages**, and a shard whose checkpoint is absent says so instead of implying an empty run. The inner run identity has one home (`shardScanRunId` / `shardScanJobId`), used by both the executor and the read. #autoclaw-001
