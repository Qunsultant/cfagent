### Added

- **Stock Copilot can preview an order at any routed broker before committing to it (#5767):** `broker_order_preview` returns the broker's own computed terms — symbol, action, quantity, order type, optional limit/stop, time-in-force, equity or options legs — for a named broker or the platform's selected one. It **places nothing and stores no draft**; invalid terms (action, type, quantity, price, time-in-force, asset-class/legs mismatch) are refused before the broker is called, an unsupported broker is named, and an unconfigured broker returns its connect-flow code instead of a generic failure. Synchronous, `mcp:trade`, acting identity required. With this, "create" terminates at an approvable draft only through the existing `propose_stock_trade` → approval flow — the execute gate stays exactly where the broker-tool mode config records it: not switchable, and no new mode was invented to move it. #ceo-aimp
