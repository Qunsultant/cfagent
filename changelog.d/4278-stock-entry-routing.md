### One engine

- **Stock entry routing (#3550 S3, #4278)**: every direct stock-screen entry now runs through the one engine seam (`src/workflows/runStockScreenViaEngine.ts`) — the broker screen, market-data research, premium sync fulfillment, NLQ port, scheduled monolithic run, and A2A `run_screen` all start a `ScreenerScreenWorkflow` job and await its collation instead of calling `ScreenerAgent.runScreen`/`runSharded` directly. Return contracts are unchanged (sync `ScreenerRunResult`, 429 already-running with run id, quota refusals, persist/deliver finalizers); a workflow-start failure answers the caller's coded failure with no silent direct fallback, and a no-binding environment now fails coded instead of falling through to a direct sync run. A sync broker screen's per-request delivery selection now follows the workflow's default delivery (carrying the selection through the command is a follow-up, not this slice).
