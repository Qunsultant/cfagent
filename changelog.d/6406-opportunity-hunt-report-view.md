### Added

- **Opportunity Hunt panel is a report-style view (#6406):** the Stock Hub sub-tab now renders the hunt output as a report — a sortable one-row-per-symbol table with pattern count, entry and exit signals, and the entry recommendation's price range (entry range, stop-loss, take-profit, externalized per strategy in `src/config/opportunityHuntLevels.ts`), plus a detail section for the selected symbol with its entry and exit recommendations grouped and a lightweight-charts price chart carrying the recommendation levels as price lines. Exit signals come from the tenant's holdings, loaded broker-neutrally from the selected broker and fed to the evaluator; when the holdings read is unavailable the run still completes on entries only and the panel states the reason. The evaluator, the run seam, and the scheduled goal are unchanged; the report (issue 6403) is deferred and must generate the same output this panel shows.
