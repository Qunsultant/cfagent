### Added

- **Neutral status and quote reads (#3293, product-neutrality #3292):** the hub read both from `/api/etrade/*`, so an Alpaca tenant saw E*TRADE status. `GET /api/broker/status` returns the selected broker's own status vocabulary plus the persisted environment, and `GET /api/broker/quote?symbol=` quotes through the selected broker. A failed status is `502 BROKER_STATUS_FAILED` naming the broker; a failed quote is `502 BROKER_QUOTE_FAILED` naming broker and symbol and carrying no quote object, so a caller can never read a zero as a price. A missing symbol is `400 invalid_request`, and a broker the catalogue says has no quote read is `501 provider_unsupported` **before** the platform is constructed. Both live in `src/agents/routes/brokerReads.ts` beside the account and position reads, and are recorded in the #359 route inventory. #ceo-aimp
