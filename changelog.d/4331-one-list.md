### Changed

- **The schedules home has one list (#4329 S2, #4331):** the options manager no longer embeds a second inventory. Every durable schedule — screening callbacks included — is one row in the one table, and the manager keeps its form, latest runs and audit trail. What made this safe is the Edit flow: the row now carries an **Edit** control that opens the manager's form for that schedule (an edit request with a nonce, so the same row re-opens), and the generic "Edit frequency" is not offered on a screening row — its cadence lives in that form. The manager's own section is opt-in (`showSchedulesSection`, default true), so any standalone mount is unchanged. With the section hidden, the page's destructive action is Delete everywhere, and the s7 pins now assert the union on the table (row badge, Resume, disabled Trigger, one Edit control) with strategy discovery under the Strategy filter it now belongs to. #autoclaw-001
