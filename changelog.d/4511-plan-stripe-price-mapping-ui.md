### Added

- Operator UI to map a plan to its Stripe Price id (#4511): a Plan Stripe Price mappings section in the Billing tab (alongside Top-up limits and Offer rules) that reads and writes `stripePriceByPlan` through the existing billing-policy route only — no new server route. The subscription checkout reads the mapping from the billing policy only, so a plan without a mapping refuses checkout with a 503; this UI is the operator path to set it. The section lists every plan with its current mapping (or "Not mapped"), saves the whole mapping wholesale (clearing a price id removes that plan's mapping), re-reads the policy after every save and renders only the fresh read, and shows fixed strings by HTTP status to operators only — a non-operator sees a fixed note with no values and no edit controls.
- "Selling options" as a sub-tab of the Products page (#4511): the catalog view and the selling view are URL-synced sub-tabs (`?tab=products&view=catalog | selling-options`, default catalog). The catalog table's Subscribe button switches to the Selling options sub-tab as well as opening the selling flow. Selling reads still happen only on demand.
- Product creation and new-version creation as sub-tabs of the Platform Admin Products page (#4511): local-state sub-tabs (Products / Create product / Create version) that never fight the parent page's `view` param. The Create product tab holds the new-product form directly; the Create version tab holds a product selector plus the version form, opened directly. Creating a product returns to the Products tab with a note.
- Product Hub menu (#4511): the product-related pages grouped under one Products menu with sub-menus — Products, Selling options, Platform Admin Products, Billing, Checkout, Payments — via the externalized nav config (the Billing precedent), with a deep link for the selling-options sub-tab.
