- **Social reward model (Qunsultant/cfagent#3477):** the reward model the #3476 program runs on, as pure rules (`src/data/socialRewardModel.ts`) + externalized config (`config/social-rewards.json`, all values null — owner/CBO-decided, fail-closed when unconfigured) + the written model (`docs/architecture/business/social-rewards-model.md`). No store, no routes, no UI, no values, no behavior change.
