### Fixed

- **The universe step serves every index, not nasdaq100 only (#5499):** `feed.universe` defaulted its index to `nasdaq100` and refused every other id by name ("maintains the nasdaq100 list only"), while the refresh service underneath already served dow / sp500 / sp100 / nasdaq100 / sp400, the 11 GICS sector lists and the three Russell lists. The step now resolves `ctx.params.index` against that one registry: any known index refreshes (a sector list and a holdings-only Russell list included), an unknown id refuses by name with the known ones listed, and an absent or blank index still means nasdaq100. The nasdaq100 job's output and descriptor are byte-identical; a run of another index records its own job id, never the nasdaq100 one. One rule, `resolveUniverseIndex`, so the parameter is checked in one place. #CAIO-quns
