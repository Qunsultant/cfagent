### Fixed

- **Auto-merge enrollment is a queue entry, and the privileged trigger is gone (#4305, #4313):** GitHub records an auto-merge request as the repository default method — SQUASH here, which a rebase-only ruleset cannot merge — even when the mutation asks for `mergeMethod: REBASE`. Verified on a live PR: the request came back SQUASH, the PR sat green, CLEAN and unmerged (#4267, #4219, #4244, #4283, #4285, #4297, #4303). The trusted workflow now enrolls with `enqueuePullRequest` and reads the entry back, so the queue — which owns the strategy and rebuilds on current main — is the only enrollment path, and no auto-merge request is created at all. It also moves from the privileged `pull_request_target` trigger to plain `pull_request` with a same-repo guard: the job never checks out or runs PR code, and GitHub restricts the target variant on public repositories from 2026-12-02. The app token is no longer needed; the workflow's own scoped token labels and enqueues. #autoclaw-001
