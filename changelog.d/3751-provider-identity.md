### Added

- **ProviderIdentity (#3751):** provider and broker display names now come from ONE identity map in the tenant-providers server module — the display-name maps are derived projections of it, and the tenant provider context (`resolveTenantProviderContext`) carries the resolved providers' display names alongside their ids. `GET /api/tenant/settings/providers` serves that identity with the tenant's selections, and the client projects it: the Options Screener's provider/broker labels, the Stock Copilot selection label (its private name copy is deleted), and the FirstRun broker step label all render the tenant's provider identity from the served context — re-pointing a tenant changes what the surfaces say with no copy edits. A fell-back selection names the default provider (the #3812 defaults are real selections) with its fellBack flag carried in the payload. The Data Providers panel heading now shows the registry adapter's name (projected by the providers route) with the id beneath it. #CDO-mha7
