### Changed

- **Run-ledger reads are D1-only — the merged (DO) read path is removed (#6103):** `/api/runs`, Workflow Runs, and `/api/runs/details` read the D1 ledgers alone (no DO read in the path, no per-tenant mode switch). Job outcomes are served from the facts already folded onto D1 `job_run_records` (new `listD1JobOutcomes` read, field-for-field from the DO list shape); stage transitions stay empty + named permanently (user ruling 2026-11-25, "no more projections"); scans, discovery, and the screener feed stay empty + named (not projected by design). The `ledgerReadMode` response field is gone, and ADR 0033 R-3/R-5 now state the single-mode world. The D1 rows still arrive via the grandfathered #6099 projector until #6101 retires it; a tenant with no carrier configured is named in `storeErrors.runs` instead of showing a silently short list. Pre-#6099 / unconfigured-tenant runs leave the view with no backfill and no sweep (replacement ruling 2026-11-25). Rollback is a revert.
