### Changed

- **Rule-of-three rationalization (#4913, sub of #3695):** the design system now caps each axis at three treatments, pinned by name in `tests/template_rule_of_three_4913.test.ts` so a fourth fails CI the way the freeze gate fails a new bespoke class. Buttons: `primary` / `secondary` / `danger` survive (ghost 138, accent 25, warning 9, trade 8 folded; `size="lg"` removed, the one use was the order submit); the Fluent Button stays contained in the two chat files (the #3146 experiment, pinned as the exception). Cards: `default` (= md) / `sm` / `none` survive (lg folded, 1 use); `elevated` + `highlight` become one `emphasized` prop; `WorkCard` (1 use) is unwrapped and deprecated; `SummaryCard` (1 use) stays with justification (no primitive equivalent for its sunken surface). Headers: all 262 hand-rolled `h2`/`h3`/`h4` sites are `CardHeader` now (229 scripted, 33 by hand); `CardHeader` gains an optional `id` prop so a section keeps its `aria-labelledby` target, and `Grid` gains an `as="dl"` prop so the run-detail definition list keeps its semantics. Utilities: `ui-scroll-x` (3) → `ui-scroll-frame` (the `min(68vh, 46rem)` cap now engages on the two long tables); `ui-stack-lg` (3) → `Grid columns={1} gap="2-5"`; `ui-stat-grid` (12 + KpiRibbon) → `Grid autoFit minColumnWidth="sm" gap="2"` (column floor 192px → 200px); `ui-form-row*` (15) → `Grid columns={2|3|4} gap="2"`; margins collapse to `ui-m-0` / `ui-mt-0` / `ui-mt-1` (the folded `mt-2`/`mb-1`/`mb-1-5`/`ml-3` become parent `Stack`/`Flex` gaps); `ui-empty-action` and the dead container/margin/scroll CSS rules are deleted. `ui-grow` (3) and `ui-clip` (1) stay (no primitive prop covers them); truncation stays two mechanisms (`ui-single-line` vs `ui-cell-nowrap` are not interchangeable); `h5`/`h6` (46) stay (a small-header decision is still open). Token-mapping doc updated in the same PR: the 6 retired heading classes move to a #4913 section, the pin drops 650 → 644, and the S-U4 rows that named `ui-scroll-x` / `ui-stat-grid` / `ui-mb-1` as successors now name their replacements. #cpo-dhmp
