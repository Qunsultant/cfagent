### Added

- **Stock Copilot trades in the sessions the user enables — around the clock, user-decided (#3398, parent #3391):** the cycle's hardcoded regular-hours gate (09:30–16:00 ET Mon–Fri) is replaced by the externalized session model in `src/services/stockCopilotSessions.ts` — pre-market (04:00–09:30), regular (09:30–16:00), after-hours (16:00–20:00) and EXTO overnight (20:00–04:00, Sun–Thu nights), all ET. Which sessions are enabled is a per-user setting resolved with the platform's AOP discipline (the login's stored `stock_copilot:sessions` setting wins, then the `STOCK_COPILOT_SESSIONS` deployment default, then regular-only — today's behavior until the user chooses otherwise; an explicit "none" is honored as the user's decision). Orders are shaped per session: market in regular hours, limit-only at the cycle's reference price elsewhere, with the session and order type recorded on every tracked position and cycle record. A session whose terms the trading platform cannot yet carry on the wire is refused by name (`stock_copilot_session_wire_unsupported`) — a regular-session order is never silently sent in its place; the wire support itself (extended-hours/overnight terms in the Alpaca platform) is filed as a sub-issue of #3398 for the platform lane. Outside the enabled set the cycle is a named, visible state — `outside_enabled_sessions` on the status route and panel, with one activity record per state transition instead of a silent skip or a record per firing. The panel gains a Trading sessions section (checkbox per session, current session marked, saving through the existing control route) and the status read reports `currentSession` + `enabledSessions`. Money-path determinism is unchanged: no prompt steps, entries still pair with exits, pause semantics unchanged. #CAIO-quns
