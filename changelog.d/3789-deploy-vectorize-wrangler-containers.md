### Fixed

- **Deploy NextGenTP green again — wrangler `containers` config rejected `image` on Durable Object-managed entries (#3789, parent incident #3781):** bb24be82 added a `containers` entry for SandboxAgent with `"image": "cloudflare/debian-trixie"` and `"scheduling_policy": "durable_object"`. Wrangler 4.156.0 rejects the `image` field on DO-managed containers (`Unsupported fields for Durable Object-managed Containers in containers: "image"...`), failing config processing for every wrangler command — so Deploy failed at its first wrangler invocation (the "Ensure Vectorize index for VectorMemory" step, 2s, exit 1) from bb24be82 on, and the #3782 and #3784 fixes sat merged but undeployed. The fix removes the `image` field from the entry; the capability is unchanged (the `class_name` + `scheduling_policy` binding stays, and the image is supplied at runtime by `ETradeSandboxService.runCommand` via `container.start({ image: "cloudflare/debian-trixie", ... })`). Proven locally with `wrangler deploy --dry-run` (exit 0, lists `SandboxAgent (durable_object)`). Pinned by `tests/wrangler_containers_3789.test.ts`. #CISO-bhdm
