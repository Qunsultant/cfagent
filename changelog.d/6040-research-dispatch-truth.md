### Fixed

- **A research dispatch can no longer report a run that never happened (#6040):** `run_research_job` passed a literal `{dispatched: true, …}` execute into a real dispatch, and the Copilot research door (`meshResearchDoor`) shipped a hollow `mode: "deterministic"` execute with no production importer. `run_research_job` now dispatches through `dispatchResearchEngineRun` with a real `ResearchDispatchTarget` — the six stage bodies plus the whole-run publish entry, composed over the orchestrator door for Worker hosts — and returns `{runId, jobId, stages}` with `jobId = research:<runId>`; a host with no way to execute refuses with `research_dispatch_unavailable` instead of answering success. The manual route's two inline stage-deps copies now use the one `createAgentResearchStepDeps` factory (which also carries the run's own trigger, the persisted feed/enrich outputs and `deferPublication` into the analyze leg), and the Copilot door is retired in place as `meshResearchDoor.deprecated.ts` with a `docs/architecture/transition/deprecations.md` entry naming its successor (gitops §22). Pin: `tests/research_dispatch_truth_6040.test.ts` fails if any `src/` module hands dispatch a literal `{dispatched: true}` receipt, and asserts the one dispatch service always returns a run id and its `research:<runId>` job id.
