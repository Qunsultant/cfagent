### Changed

- **Audit-before-write for channel mutations (#5867):** every channel mutation (PUT webhook-url, PUT slack-channel, PATCH channels, on the HTTP path and the BizCopilot path) now writes its IAAA audit record BEFORE the D1 write, through `recordAuditEvent` over the wired store, per the E5 audit-before-allow policy. A failed audit write blocks the mutation with the new coded 503 `FAILURE_COMMERCIAL_AUDIT_REQUIRED` and no D1 write runs. The turn-level `platform-channel-admin` funnel annotation after the write is unchanged. Residual (documented, not solved): a D1 write failing after a successful audit append leaves an audit record for a change that never landed — the chain has no rollback for this; the SessionStore-in-D1 question (#5868, CDO lane) could close it.
