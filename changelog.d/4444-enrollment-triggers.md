### Fixed

- **Green, ready PRs enroll themselves again (#4444 / #4325 / #4346):** the enrollment job ran only on `workflow_run`, which GitHub never delivers for PR-branch runs here — every delivery was a main-branch run — so a green PR sat unenrolled until a human clicked. Enrollment now runs on `pull_request` (payload resolution, immediate when the head is already green), a **5-minute schedule** that sweeps open `auto-merge` PRs and enrolls each green, conflict-free one, and manual dispatch. The ready half (`auto-ready-drafts`) is now a 5-minute sweep too, so the flip and the enrollment are two halves of one cadence instead of a dead trigger. Invariants kept: label-gated, draft-skipped, App-token queue call, rebase-only queue, and the #4317 read-back that fails loudly when the entry did not land. #autoclaw-001
