### Added

- **The Public.com deployment credential is an explicit fallback with a named source (#4048):** an operator may configure `PUBLIC_API_KEY`, read by `publicDeploymentToken` (`src/security/publicOAuth.ts:290`) — a **fallback, never an override**: a login's own stored token always wins, and the deployment key is only consulted when the login has none. Because one deployment key is one account shared by every tenant, the source travels with the answer: `getPublicCredentialSource` (`src/security/publicOAuth.ts:325`) reports `"user"` or `"deployment"` (never the token itself), and the status surface reports a deployment credential as `connected: true, verified: false` with no token hint, so a shared key is never presented as a personal account.
- **The deployment credential cannot trade (#4048):** every mutating Public platform call refuses a deployment-sourced credential (`refuseDeploymentCredential`, `src/trading/public/platform.ts:136`), so a configured `PUBLIC_API_KEY` buys reads only — placing, previewing and cancelling still require the user's own connected token.
- **`deploy.yml` syncs the Public.com secrets (#4048):** a "Set Public.com secrets on Cloudflare Worker" step mirrors the existing `ALPACA_*` block, pushing `PUBLIC_API_KEY` and `PUBLIC_LIVE_URL` through `scripts/ci/put-secret.sh` with `optional_secret` — an absent value warns and skips rather than failing the deploy, so a deployment without them keeps serving the per-user connect flow.
- **`public_account`, a read-only Public account tool (#4048):** returns the account(s), cash available / buying power and every open position with quantity, average cost and unrealized P&L when Public sends them, as `provenance: "live"` data (Public has no paper mode) carrying `credentialSource` so the caller can say whose account was read. It never places, previews or cancels an order, and it is scoped `mcp:read` in `MCP_TOOL_SCOPES` (`src/mcps/openaimp/mcpPermissionPorts.ts:191`); the sync-tool classification (`SYNCHRONOUS_MCP_TOOLS`, `src/config/asyncJobModes.ts:366`) also makes it answer in the turn it is asked instead of returning a queue receipt.
