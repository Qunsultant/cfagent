### Fixed

- **Data Hub tab strip no longer collapses to an invisible 1px line (#6501):** on `?tab=data-hub&view=pipeline-policy` the strip rendered ~13px tall with zero label pixels — all five tabs present in the DOM, none visible. Root cause: inside the height-constrained flex column, the panel's min-content height (1699.5px) exceeded its flex-basis so it froze, and the strip — a scroll container with zero automatic minimum size — absorbed the whole overflow. `.ui-tabs` in `src/client/components/ui/primitives.css` now carries `flex-shrink: 0`, so the overflow stays with the panel, which scrolls via the tab-viewport; the strip stays fully content-derived (font + padding tokens), one rule, all pages benefit. Verified in real layout (Firefox): tablist 1px → 38.5px, all five tabs 37.5px. DataHubHome also migrates from PageShell to PageTemplate (one-token swap; PageTemplate renders PageShell, so migration alone does not fix the strip — the shared-layer rule does), and the #4825 composed-page gate now asserts rendered tabs == registry tabs (count + labels, in registry order) for every tabbed template route.
