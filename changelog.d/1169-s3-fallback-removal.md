### Removed
- Agent search no longer answers from a built-in stub corpus: the hardcoded FINANCIAL_KNOWLEDGE_BASE fallback in the AI Search service is removed (#1169 S3). Search now answers only from the live Cloudflare AI Search index; when the index is unavailable or unconfigured, the Search hub's agent tab, the ai_search_financial_docs tool, and the AiSearchAgent say so explicitly (a visible "Live index unavailable" notice / a degraded result with a machine-readable reason) instead of showing substitute documents. An index that is reachable but empty still returns an honest zero-results answer, distinguishable from an outage.
