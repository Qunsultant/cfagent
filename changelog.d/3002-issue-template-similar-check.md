### Added
- Issue templates (bug report, enterprise architecture, task) now require a pre-creation similar-issues check: list same/similar issues by reference with a covers/overlaps/distinct verdict, or state "None found" with search terms; duplicates must be comments on the existing issue instead (#3002).
- Issue templates also carry a Small / Medium / Large size estimate (one checkbox) so the work is sized at creation (#3002).
- Issue templates prompt the cross-lane rule under Dependencies: link the other lane's separately created and assigned issue; never fold another lane's work into your own issue (#3002).
