### Changed

- **The Fluent chat-chrome experiment is over — the chat now runs on tokens.css and primitives.css (#5843):** `ChatComposerVoiceControl` and `AgentChatTabContent` were the two #3146 Fluent v9 files, and they were the last `@fluentui/react-components` imports in `src/client`. Both now use ui/ primitives: Fluent's dialog became `Modal`, its `MessageBar` became `Notice`, its `Input` became `TextInput`, its `Badge`/`Button`/`Spinner` became the ui equivalents, and the five Griffel blocks became tokens-only classes (`.ui-chat-*`) with the same declarations — so the split workspace, the chips bar, the viewport and the composer keep their layout without a runtime style engine. The composer's mic and audio controls still render **inside** the input box (#3794): `TextInput` gained a `trailing` slot and a `.ui-input-shell` / `.ui-input-bare` pair, so a field can carry an in-box control with the shell owning the border and focus ring. The Fluent theme plumbing (`readFluentTheme`, the `theme-changed` listener, the unused `useToastController`) is deleted — the app theme already applies. Both pins flipped with the migration: `template_rule_of_three_4913` now requires **zero** client files to import Fluent, and `ux_primitives_exceptions_1772` drops its Fluent list (44 → 43 exceptions). `repoRel` in the template pin also normalises to POSIX separators, so its `ui/` exclusion holds on Windows instead of counting primitive headings as page headings. #ceo-aimp
