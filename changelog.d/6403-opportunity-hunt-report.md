### Changed
- Opportunity Hunt report (issue 6403): the hunt's output is now downloadable as a coloured PDF from the panel. The report renders the same output the panel shows — one row per symbol with pattern count, entry and exit signals grouped per entry and per exit with their price ranges, a per-strategy breakdown chart, a per-symbol pattern-count chart, and a price chart carrying the recommendation levels. Generated through the unified report pipeline (type `opportunity-hunt`) via the ReportAssetAgent into the canonical report store, and downloaded via `GET /api/opportunity-hunt/report.pdf`.
