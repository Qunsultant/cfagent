### Fixed

- **`screener-screen-workflow` never reached `run()` (#4140).** Every instance — 324 of them, zero completed — died in about two seconds with zero steps: `AgentWorkflow requires __agentName, __agentBinding, and __workflowName in params`. `ScreenerScreenWorkflow` extends `ThinkWorkflow`, whose base `AgentWorkflow` validates those keys *before* `run()`, and the start path passed only the bare job command. `startWorkflowInstance` now supplies the three keys (`__agentName` from the command's login, `system` when absent; `__agentBinding: ORCHESTRATOR_AGENT`; `__workflowName` from the binding), so a start reaches the workflow's own code. Pinned by `tests/screener_workflow_agent_context_4133.test.ts`. No schedule is restored — the retired `*/30` trigger was the source of the 324 firings, not their cause.
