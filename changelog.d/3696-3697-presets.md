### Added

- Navigation presets + visible tabs move to a Navigation Settings page (`?tab=nav-settings`, issues 3696/3697): eight presets (All Tabs, Research, Trading, Payment, Marketing, Platform, Minimal, None) computed from the left-nav config, with pills for all 26 config items; the `none` preset persists as an explicit empty selection that survives reload.
