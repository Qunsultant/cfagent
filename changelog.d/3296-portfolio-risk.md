### Changed

- **Portfolio risk is a declared capability (#3296, product-neutrality #3292):** the eight `/portfolio-risk*`, `/hedge/analyze`, `/portfolio-repair/analyze` and `/think/evaluate` routes read the E*TRADE portfolio model, so a non-E*TRADE tenant could not have them — and the surface said so with a bespoke string rather than a contract. `portfolioRisk` now joins `BrokerOperation`: E*TRADE `true`, Alpaca `false`, stated for every broker so a new one cannot omit it. The decision recorded with the code is **no second risk engine in this build**; if a customer needs risk under Alpaca, that is a separate slice with a reconciliation fixture against E*TRADE's numbers, because two engines producing different risk for one portfolio is worse than an honest absence. `portfolioRisk` is deliberately distinct from `positions`, which Alpaca does support. #ceo-aimp
