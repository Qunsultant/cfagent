### Fixed

- **Deploy NextGenTP permanently resilient against Cloudflare Containers API permissions (#3789):** Added `scripts/ci/deploy-worker.mjs` to execute `npx wrangler deploy` with automated fallback. If the Cloudflare API token or account lacks Cloudflare Containers entitlements (returning HTTP 403 Forbidden on `/containers/applications`), the deployment step automatically strips the optional `containers` configuration block from `wrangler.jsonc` in the runner and redeploys the Worker in honest degraded sandbox mode (per `src/agents/sandbox-agent.ts`). Production deployments will never be blocked by missing Cloudflare Containers permissions, while preserving the container declaration for environments with container provisioning enabled. Pinned by `tests/deploy_worker_3789.test.ts`. #CISO-bhdm
