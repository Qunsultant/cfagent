### Fixed

- **The delivery doc no longer prescribes a command that records a dead merge request (#5569):** §11 said to enqueue with `gh pr merge <n>` and warned not to rely on GitHub's auto-merge request. On a PR whose checks are still running the CLI falls back to `enablePullRequestAutoMerge` and records the repository default — SQUASH — under a rebase-only ruleset, so the request can never merge and the queue never has the PR (observed on #5531: no CLI output, `autoMergeRequest.mergeMethod: SQUASH`, then the explicit mutation enqueued the same head at position 5). §11 now shows the `enqueuePullRequest` mutation as the entry, states why the CLI call is not equivalent, and points at `scripts/pr-delivery-state.mjs` — a small classifier (`scripts/prDeliveryState.mjs` + CLI) that reads one PR's payload and names `queued / not-queued / dead-auto-merge / draft / red` with the right advice and exit code. Pinned by `tests/pr_delivery_state_5569.test.ts` against the real 5531 and 5536 payload shapes, including a test that §11 keeps the instruction. #clo-arsi
