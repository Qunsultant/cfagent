### Pipeline J3 (#3536): enrich jobs on the uniform job plane — one enrich job per quotes feed job (Yahoo Nasdaq-100, Yahoo S&P 100, Alpaca, E*TRADE, Public), consuming the feed stage's persisted datasets and publishing enriched datasets for the analyze stage
- Enrich jobs (#3536): every enrich job is one J1 job definition on the uniform plane — individually schedulable, configurable, and manageable (run/pause/resume/cancel/retry plus the seven stage operations) — whose single `enrich.apply` step runs on THE composed step registry (the feed steps plus enrich, built identically in the ScheduledAgent host, the workflow start path, and the workflow residency; no second engine entry). A run resolves its feed job's newest usable PERSISTED dataset by exact lineage (never a live re-fetch; never a sibling job's copy in the shared (source, dataset) bucket), computes the elements its externalized configuration names, and persists the enriched artifact — run records ride the JobRunRecordStore machinery (system "job-pipeline") and the pipeline run id is the enriched artifact's run id. The hand-off is two-sided: a recorded feed completion dispatches the consuming enrich job on the host (the queue publication is the trigger, never the data channel), and every enrich job is independently schedulable/runnable like any job on the plane. A missing persisted input refuses BY NAME (ENRICH_INPUT_MISSING, fail-closed, with the failed run recorded); an unwired store refuses ENRICH_JOB_NOT_CONFIGURED.
- The element vocabulary is configuration, not code (step params, changeable through configureJob; env knobs ENRICH_JOB_<JOB_ID>_CADENCE_MINUTES / _STALE_MINUTES / _ELEMENTS shape the built-ins): snapshot derivations (momentum, intraday position, day range, gap, relative volume, VWAP deviation, spread, 52-week range position), the platform's snapshot screening indicators (sentiment, range/value zones, screen score), a by-symbol join of persisted fundamentals (P/E, PEG, price/book, beta, margins, ROE, analyst target + derived upside, recommendation), and series indicators (SMA, Bollinger) computed over the PERSISTED SNAPSHOT SERIES with that basis recorded on the artifact. Elements the persisted inputs cannot support are recorded unavailable with coded reasons — never fabricated: RSI/MACD/ATR name `requires_daily_bar_history` (no feed dataset persists bars), thin series name `insufficient_snapshot_series`, absent fields name `field_not_in_snapshot`, join misses name their dataset/symbol reason; a configured-but-missing join dataset yields a partial run with the gap recorded.
