### Added

- **Stock Copilot can now start, pause, resume, cancel and retry a whole job over MCP (#5739):** the engine (`JobPipelineControl`) and the `ScheduledAgent` host already implemented the job-level verbs, but only per-stage control had a chat surface (`stock_copilot_stage_control`, #4362), so an operator asking chat to pause or cancel a job was told the capability did not exist. The new `stock_copilot_job_control` tool takes `(jobId, operation)` with `start | pause | resume | cancel | retry` and dispatches through the one door to the existing engine RPCs — no second control plane, no new store. Meanings are the engine's pinned ones: `pause` is cooperative (honored at the next step boundary, the run stays resumable and is never failed), `cancel` is terminal (downstream stages never proceed), `resume` continues from the persisted checkpoint. Control keeps the stage tool's operator gate: a missing or retired-synthetic identity is refused before dispatch, an unknown job refuses by name, and an absent binding is a named door failure rather than a pretend success. #ceo-aimp
