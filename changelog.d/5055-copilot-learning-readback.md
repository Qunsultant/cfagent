### Added

- **Stock Copilot agentic cycle now reads its own learnings back into planning (#5055, AG-1):** the loop distilled a learning every cycle into `stock_copilot_learnings` and never read one — the header claimed a perceive-step read that no code performed. `runStockCopilotAgenticCycle` now calls `listLearnings` in its perceive step and applies two stated rules from the new `src/services/stockCopilotLearningPolicy.ts`: **risk** learnings at/above `COPILOT_LEARNING_RISK_BLOCK_AT` (default 2) hold back NEW entries while exits still execute (a risk lesson must never trap an open position), and **session** learnings at/above `COPILOT_LEARNING_SESSION_LIMIT_AT` (default 2) force limit-only order shaping, including the regular session where the default shape is a market order. The policy travels in the cycle result (`plan.learningsPolicy`) and its reasoning line, so a no-trade cycle states which learning held it back. Every threshold is externalized (`COPILOT_LEARNING_POLICY_WINDOW`, both thresholds, and the `COPILOT_LEARNING_READBACK_ENABLED` kill switch, declared in `src/types.ts` and documented in `.dev.vars.example`); an unreadable memory port fails open and is recorded as a `learning_readback` cycle error rather than halting trading. Pinned by `tests/stock_copilot_learning_readback_5055.test.ts`. #clo-arsi
