### Added

- **Stock Copilot v1 — continuous pattern loop on Alpaca paper (#3391, parent #3380):** a Think scheduled task (`every 30 minutes`, per-login orchestrator instances) runs a deterministic cycle — live bars → the sandbox strategy set's signals, extracted into the shared `src/services/patternSignals.ts` (the sandbox backtest now delegates to the same module; its outputs are parity-pinned) → portfolio sizing (#36/#1769) against the live book's risk report (#34) → the CVaR optimizer gate (#1361, a trade must beat no-trade over a scenario grid built from the signal's own in-series forward returns) → market orders through the Alpaca `TradingPlatform` seam. Every opened position is tracked with its exit plan (stop −5% / target +10% policy, plus the strategy's own exit signal) and exits are evaluated before new entries each cycle. Hard boundaries: flag `STOCK_COPILOT_PAPER_ENABLED` default OFF (flag-off instances declare no task and place no orders), and a paper-only guard that resolves the Alpaca environment through the adapter's own #3158 resolver before any platform call — a live resolution refuses the cycle with `stock_copilot_live_environment_refused` and zero orders. Live trading is untouched and remains a separate owner activation decision. #CAIO-quns
