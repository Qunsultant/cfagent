### Added

- **Stock Copilot can create an order on any routed broker, in one synchronous call (#5767):** `broker_order_create` proposes on the selected broker (or a named one) through the existing TradingAgent door and submits the proposal to the approval workflow in the same call, returning the broker's pending-approval proposal and the approval run's id. It **places nothing** — a human decides the approval and the workflow's settle step executes, so the execute gate stays exactly where the broker-tool mode config records it. Invalid action, quantity or price is refused before a broker is called; a broker that returns no proposal is reported with its own status instead of an invented success. Synchronous, `mcp:trade`, acting identity required. With cancel (#5765) and replace (#5766) already live, the neutral order family is complete end to end: preview → create → approve → settle, plus cancel and replace in place. #ceo-aimp
