### Added

- Referral trial-extension model (#6141): per-referral trial extension (PROPOSED 7 days per referred first verified paid run), accumulation with banking as free days when no trial is active (expiry per the 90-day referral rule), daily/monthly caps, and an audit row for every grant. The referred user is granted a PROPOSED 14-day trial on signup via the link on the operator-chosen trial plan. Extension values are externalized on the referral rule row (migration 0082) and operator-managed in the Billing referral-rules section. Each signed-in user sees their referral link, earned extensions, banked days, trial end date, and referred-user count in a referral panel under their profile. The extension is time only (D-2.25): it never mints a subscription, never pays for a plan, never converts to credits.
