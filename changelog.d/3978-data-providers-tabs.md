### Added

- Data providers multi-tab view (#3978): the Platform Admin data-providers page (`?tab=platform-admin&view=data-providers`) now shows an Overview tab (default) listing all providers with summary status, one tab per provider with that provider's full details (feed status, feed-job schedule editor, pipeline jobs, lifecycle actions, connectivity, capability routes), and an Add provider tab holding the register form. Each provider name on the overview is a deep link to its tab via the new page-owned `providerTab` URL param (`?providerTab=<id>`), which survives back/forward, falls back to Overview for unknown values, and drops when navigating away from platform-admin. No backend changes; no provider detail, action, or diagnostic was removed.
- Back/forward to a URL that names no tab now adopts the default tab in the shared `useUrlSyncedTabs` hook (#3978): previously the route subscription ignored a param-less URL and kept the previous URL's tab, so Back from a provider tab to the bare data-providers URL left the provider tab showing. The bare URL now addresses the default tab, as the URL-as-source-of-truth contract implies.
