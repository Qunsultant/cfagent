### Added

- **Stock Copilot on any catalog broker/mode (#3839):** the broker catalog now declares each broker's copilot capability — `supported`, `autonomousCycle`, `bracketOrders` (`native` / `preview` / `none`), `percentBrackets`, `barsProvider`, and the quote/preview/place/history/cancel tool names. The copilot gate, door status, broker-neutral mode guard, scheduled host, and prompt steering read that declaration instead of hardcoding Alpaca, so Alpaca paper/live and E*TRADE paper/live all run, and a future broker is one catalog entry plus its registry registration. E*TRADE preview now converts `+4%/-2%` exits to exact legs and refuses bracket placement honestly (preview-only; separate exits), while Alpaca keeps native bracket placement. Residual RCA fixes: E*TRADE and mesh trading tools are synchronous, Alpaca refuses non-day brackets before broker contact, and the NLQ order fast-path parses take-profit/stop-loss percentages.
