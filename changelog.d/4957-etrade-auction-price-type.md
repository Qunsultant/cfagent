### Added

- **E*TRADE auction orders (MOO / MOC / LOO / LOC) as its own documented price types (Qunsultant/cfagent#4957):** the previous slice refused an auction time-in-force on E*TRADE because no order *term* expresses it — and none does. E*TRADE expresses the same four orders as **`priceType`** values (`MARKET_ON_OPEN`, `MARKET_ON_CLOSE`, `LIMIT_ON_OPEN`, `LIMIT_ON_CLOSE`), so the seam now maps the (order type, time-in-force) pair onto exactly those and sends nothing new: a MOO and a MOC are market orders with the open/close price type, a LOO and a LOC are limit orders with theirs (and the limit price rides along, because `LIMIT_ON_*` is limit-bearing). A stop in an auction, or an option order with an auction term, is still refused **by name** before any POST — E*TRADE documents neither — so nothing is ever downgraded to a plain day order. The capability matrix lists `OPG`/`CLS` for E*TRADE equity (paper and live, not options), and the registry's `session_timed` entry is now native on both brokers that document it.
