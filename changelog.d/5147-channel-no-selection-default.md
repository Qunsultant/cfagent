### Changed

- **One no-selection default for the channel desks (#5147, follows #5131/#4999/#3937):** an unselected tenant's voice, NLQ and Slack order used to fall back to a channel-only broker while the same tenant's neutral routes and hub used the platform default (`DEFAULT_TENANT_PROVIDERS.brokerId`, #3937). `src/trading/channelBroker.ts` now resolves that one default (`resolveNoSelectionBroker`), `config/channel-brokers.json` records the policy (`noSelectionDefault: "platform"`; `"legacy"` is an explicit escape hatch that honours only a known broker id), and `docs/architecture/business/brokerage-data-matrix.md` §0.1 records the decision. A selected tenant is unaffected. Pins: `tests/voice_nlq_slack_neutral_4664.test.ts` (resolution + policy cases) and the channel suites, which now state their E*TRADE selection explicitly.
