### Added
- Search Hub: new "AI Search Agent" tab (issue #3323) backed by `POST /search/ai-agent`, which dispatches to the real AiSearchAgent through the `AI_SEARCH_AGENT` Durable Object binding — the agent searches the instance namespace-first (then MCP, then REST), the answer is labelled with the serving path, and the route threads the session login as `callerLogin` so report-type results are served only to their owner. A degraded or unserved agent answer renders as a visible notice with the agent's note/error verbatim; nothing is fabricated. The pre-existing "Search Agent" tab (service-direct) is unchanged.
