### Added

- **Per-step timeout for the MAS turn loop (Qunsultant/cfagent#5423):** `generateText` now runs with the AI SDK's `timeout: { stepMs }` (ai 7.0.123), so a step exceeding the tenant's configured timeout aborts with a named `TimeoutError`, recorded on the run as `turn.step_timeout`; the step-count cap stays enforced alongside. The timeout is externalized tenant-scoped config — a nullable `turn_step_timeout_ms` column on `agent_tenant_settings` (migration 0078), readable and writable through the CommercialStore port and the tenant admin panel (PATCH `/platform-tenants/:id/settings`, 1000–600000 ms). An unconfigured timeout is a named refusal (`turn_step_timeout_unconfigured`): the turn refuses before any model call instead of running unbounded. Timeout events go to the S2 structured logger with the 7 mandatory attributes.
