### Changed

- **Index presets resolve stored membership; a preset no longer wears an index's name over a hand-written subset (#3936):** `NASDAQ100`, `SP100`, `SP500` and `DOW` now map through one `INDEX_PRESETS` table to an `IndexId`, and `resolveCopilotUniverseFull` resolves **any** of them through `resolveStoredIndexList` with the same labelled-fallback contract (`source: "preset-fallback"` plus a reason naming the cause). Before this, only Nasdaq-100 was index-backed; `SP100` returned 12 hand-picked symbols while claiming an index, and `SP500`/`DOW` did not exist. The status surface (REST, mesh door, and the panel sentence) now reports the resolution the cycle runs — `source`, member count and snapshot date — instead of the sync preset, so "SP500 · 100 members · snapshot 2026-11-07" is distinguishable from "SP500 · 1-symbol labelled fallback"; the sync resolver still returns the preset array and is never read as membership. `MEGA_TECH`, `SEMIS` and explicit symbol lists stay `source: "configured"`.
