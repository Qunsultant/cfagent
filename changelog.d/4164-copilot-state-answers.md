### Fixed

- **The Stock Copilot answers "how many strategies" and "which broker in which mode" from its own status payload (#4164).** Asked both, it called `stock_copilot_status`, then searched platform knowledge, got "No custom index documents matched", and synthesized an answer anyway — an answer that could quote the 74-entry **options** catalog for a stock loop that runs two strategies. The payload always carried the truth (`strategies`, `activeBroker`, `activeMode`); the tool description never named them and no prompt rule said they were the answer. The status description now names all three fields and both question classes, both prompt blocks route the questions there, and a new rule states the grounding: *state questions are read, not synthesized* — a missing field is reported as missing, never filled from general knowledge.
