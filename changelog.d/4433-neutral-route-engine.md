### Added

- **Neutral stock screen now runs on the one engine (#4433, #3550 S5b):** `POST /api/broker/screen` executes through `runStockScreenViaEngine` as a `ScreenerScreenWorkflow` run and writes a run record, ending the neutrality/observability mutual exclusion on that surface. The route's contract is unchanged: the tenant broker is resolved and names the run's provider + broker, a broker without a quote read still answers loud `501 provider_unsupported` before any start, no substitution, no curated fallback, and the 25-symbol cap stays. A broker the engine has no quote binding for is refused the same way before any start. The response keeps the client contract (`stocks`, `totalScreened`) and gains the run-record linkage (`jobId`, `workflowId`, `statusUrl`); per-symbol quote failures surface from the engine run's own quote trace.
