### Added
- Receipts/ledger surfacing for the single user (issue #2543, Monetization Phase 1.4, sub-issue of #2405): GET /api/payments/receipts returns the caller's own meter rows (usage_events, with detail_json), tier-decision audit rows (mas_events commercial.tier.decision, new idx_mas_events_session_type index), and joined gateway rows (mas_transactions by PRIMARY KEY tx_<receiptId> plus a bounded customer=login query) — newest first, capped at 100, with a derived per-row provenance (Real / Simulated / Audit) and counts by kind and provenance. No money totals: a sum over mixed provenance would read as revenue. The Agentic Wallet panel gains a display-only "Paid-call receipts" section over the same surface. Read-only: surfacing never confirms, moves funds, or replays a charge; HITL draft→confirm is preserved on every payment/refund touchpoint. No new tables, flags, cron, or queue.
