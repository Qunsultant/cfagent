### Copilot-Autopilot Bridge, Autonomous Mode & Broker-Neutral Prompts (#3846)

- Added architecture documentation (`docs/architecture/agentic/copilot-autopilot.md`) detailing the separation and bridge between the Interactive Chat Copilot and the 24/7 Background Autonomous Autopilot Loop (`pre_market`, `regular`, `after_hours`, `exto`), `RiskPolicyEngine` deterministic guardrails, W3C Agent DID Verifiable Credential attestations, and broker-neutral prompt assembly.
- Extended `stock_copilot_status` and `stock_copilot_control` (`src/agents/orchestrator/meshStockCopilotDoor.ts`, `src/mcps/openaimp/meshDoorCommands.ts`) to expose and control Autopilot runtime state (`autopilotRunning`, `killSwitch`, `killSwitchReason`, `autopilotLimits`) and interactive chat execution mode (`copilotExecutionMode: "hitl" | "autonomous"`).
- Made `src/agents/chatPrompt.ts` and `src/agents/prompts/stockCopilotPrompt.ts` broker-neutral and driven by `resolvePromptBrokerTools(input)` (`activeBroker`, `activeMode`, `copilotExecutionMode`), eliminating legacy hardcoded E*TRADE OAuth/preview strings when running in Alpaca/Paper mode and enabling immediate order execution (`tool_openaimp_alpaca_place_order` / `tool_openaimp_etrade_execute_order`) when `copilotExecutionMode === "autonomous"`.
- Added `isStockCopilotIntent` automatic `sourceTab: "Stock Copilot"` elevation in `src/agents/orchestrator/chatTurnHelpers.ts` and `src/client/chat/AgentChatTabContent.tsx` so stock trading, bracket (`+4% take-profit and -2% stop-loss`), and autopilot commands submitted from General Chat route to the Stock Copilot domain.
