### Changed

- **Stock screening reaches the UI for any broker (#3272 stock UI):** `/api/broker/screen` now resolves a **named universe** (`POST { universe }`, default `NASDAQ100`) through the live Nasdaq listings feed and scans a bounded slice of it, instead of requiring a hand-written symbol list — which is why the hub could not be repointed before. The response says what it did: `universe`, `universeSize`, `truncated` (true when the scan covers only part of the universe), `requested`, `quotesRead`, plus the screen result spread at the top level so the existing client contract (`stocks`, `totalScreened`) is unchanged. A failed listings feed is `503 LISTINGS_UNAVAILABLE` — **no curated table is substituted**, following the rule #1554 set for listings. The trading hub's stock screen now calls `stockScreenEndpoint()` (#3272 S5) instead of the hardcoded `/api/etrade/screen`, so an Alpaca tenant screens Alpaca's quotes while an E*TRADE tenant keeps the legacy engine, universe discovery and paid seam untouched. #ceo-aimp
