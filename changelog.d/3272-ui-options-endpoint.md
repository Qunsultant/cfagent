### Changed

- **The options screen follows the broker selection in the UI (#3272 S5):** `OptionsResearchPanel` and `RawContractsScreener` hardcoded `/api/trading/options/screen`, so a tenant on Alpaca was sent to a route that cannot answer for it. Both now resolve through `src/client/brokerEndpoints.ts`: E*TRADE keeps its own route (paid seam, server-side gating and behaviour unchanged), every other broker gets the neutral `/api/broker/options/screen` (#3272 S1). The rule has no fallback — an unknown or empty selection is treated as non-E*TRADE and gets the neutral route, whose refusals are coded (`501 provider_unsupported` naming the broker) rather than silently wrong. The same helper exposes `stockScreenEndpoint` for the stock surface, so the two screens can never disagree about which broker they are talking to. #ceo-aimp
