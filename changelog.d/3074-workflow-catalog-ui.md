### Added

- **Workflow & stage catalog page (#3074, #3069 S4):** a new **Catalog** sub-tab in the Workflows hub (`?tab=workflows&view=catalog`) renders every workflow the registry declares — read straight from `src/workflows/workflowCatalog.ts`, no second list. Each workflow card shows its id, family, stage count and `Runnable` / `Read-only` state; each stage row shows its four mode axes (timing, concurrency, volume, partitioning), the producer→consumer chain (`consumes → persists → publishes`), its retry bucket, its checkpoint flag, and an `Approval required` badge where the stage is gated. A workflow declared `runnable: false` renders a "No submission path yet" notice and offers no Run action. Built from `ui/` primitives with token-only CSS classes and **no inline styles** (the #3047 per-file budget is untouched); 6 panel pins plus the UX-conformance and primitives-inventory suites green.
