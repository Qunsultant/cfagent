### Options report scope — one config for theses, strategies, chains, formats and channels (#2583)

- New `config/options-reports.json` declares every axis an options screening report varies on: theses, strategies (`"all"` = the 74-entry registry, or a list of ids/aliases), chains (symbols/universe/DTE band/contract caps), risk gates, formats and delivery channels, with presets `full`, `thesis`, `quick`, `all-chains`. Resolution precedence is request > `OPTIONS_REPORT_CONFIG`/`OPTIONS_REPORT_PRESET` > preset > built-in. Producing one, some, or all of any axis no longer needs a code change.
- New `src/trading/optionsReportScope.ts` resolves the scope, reports provenance and structured warnings, names the strategies the configured DTE band cannot reach (`horizonLimited`), plans one execution per thesis (`thesisRunPlan`), and renders the scope in one ASCII line for audit rows and report headers. A bad value never fails a run: unknown ids, out-of-vocabulary theses/formats/channels and malformed env JSON are dropped with the ignored value named.
- Strategy reports now state their own coverage: the PDF gains a `Scope:` line, a `Coverage: n of m wanted strategies reported` line and up to 12 named not-reported strategies with the reason (skipped by the engine / not thesis-aligned / horizon-limited / evaluated-but-unranked / never evaluated); the XLSX gains `Coverage` and `Coverage Summary` sheets. The CSV column contract is unchanged.
- Scheduled options runs resolve the scope once and pass the wanted set plus gates into both the sharded chain and the monolithic scan, stamping `describeReportScope()` into `options.sharded_chain_submitted`.
- The sharded per-symbol executor now forwards `minDte`/`maxDte`/`maxPlannedLoss`/`minRewardRisk` from the scope. It previously hardcoded 1000/1.5 and dropped the DTE band, so the same schedule could produce different candidates depending on whether it sharded.
- Defaults reproduce today's behavior exactly: `dte: null` keeps the engine's thesis band, gates stay 1000/1.5, formats stay PDF+XLSX+CSV.
- Inventory and diagnosis (6 report types x 3 formats x 7 channels; failure classes F1–F8; the three causes of a "3 strategies" report) recorded in `docs/agents/options-report-inventory.md`.
